Project Badges & Overview: Babylon.js 9.36, React 19, TypeScript ES2022, Colyseus 0.18, Vite 8, and Tailwind CSS v4.
Key Gameplay Systems:
Fluid Movement: Jump buffering (0.16s), coyote time (0.12s), high air acceleration (9.0 m/s²), and tactical sliding with jump-canceling.
Weapons & Ballistics: M4A1 Tactical, MP5-SD, Intervention .50 (with mil-dot 4X/6X/8X optics & rangefinder), and M1911 Sidearm.
Tactical Bot AI (Offline): Fair line-of-sight checks (no wall-hack tracking), distance-scaled spread, humanized reaction delays, and unstuck navigation.
Multiplayer Engine: Authoritative Colyseus WebSocket rooms with client-side prediction and 6-character room codes.
Web Audio Engine: Procedurally synthesized audio with ascending kill confirmation chimes, weapon equip clicks, low-ammo clicks, and critical health heartbeat audio.
Killstreaks & Progression: UAV Sweep (F1), Precision Barrage (F2), and Overdrive (F3) with persistent rank/XP tracking.
Controls Reference Table: Clear keybinding guide for all movement, combat, weapon cycling, and menu shortcuts.
Installation & Scripts: Step-by-step setup (npm install, npm run dev, npm run build, npm start, npm run lint).
Project Architecture Map: Directory tree mapping backend, bots, game controller, maps, multiplayer, and UI components.
Accessibility & Settings: Field of View, mouse sensitivity, screen shake & flinch scaling, and audio sliders.
